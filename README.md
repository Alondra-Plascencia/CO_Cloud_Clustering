# Molecular Cloud Clustering & Distance Estimation (`CO_Cloud_Clustering`)

This repository provides a complete pipeline for the morphological clustering and Bayesian distance estimation of molecular clouds (specifically applied to **DR21**) using CO isotopologue spectral data cubes ($^{12}\text{CO}$, $^{13}\text{CO}$, and $\text{C}^{18}\text{O}$ $J=1\text{--}0$) combined with **Gaia** astrometric and photometric star catalogs.

---

## Repository Structure

```text
.
├── data/         # Original spectral data cubes (.fits) for 12CO, 13CO, and C18O (J=1-0), and Gaia star catalogs (.vot, .csv).
├── fitsfiles/    # Processed FITS files generated by the pipeline (smoothed cubes and Moment 8 peak intensity maps).
├── modules/      # Core Python source code and pipeline scripts.
│   ├── Distance/             # Bayesian parallax-to-distance conversion package (pyrallaxes & distance estimators).
│   ├── module_clustering.py  # Dendrogram computation (astrodendro), catalog generation, mask extraction, and cluster plotting.
│   ├── module_data_path.py   # Helper functions to resolve project directory paths dynamically.
│   ├── module_utils.py       # Utilities for cube moments, smoothing, Gaia filtering, isotonic regression, and MCMC sampling.
│   └── run_clustering.py     # Main entry-point script defining and executing the 5 pipeline stages.
├── notebooks/    # Exploratory Jupyter notebooks for interactive dendrogram visualization and VOTable inspection.
├── plots/        # Output figures (.pdf) including Moment 8 maps, dendrogram contours, ellipse fits, baseline fits, and MCMC corner plots.
├── catalog/      # Output catalogs (.csv, .json) from dendrogram extraction, Gaia star classification, net extinction, and final cloud distance.
├── mask/         # Output 2D/3D boolean masks (.npy) for cube edges and identified molecular cloud structures.
├── environment/  # Conda environment configuration directory.
└── README.md     # Repository documentation.
```

## Conda Environment Setup

Inside the `environment/` directory, the `environment.yml` file defines a dedicated Conda environment with all required dependencies (such as `numpy`, `scipy`, `pandas`, `matplotlib`, `astropy`, `spectral-cube`, `astrodendro`, `scikit-learn`, `emcee`, `corner`, `uncertainties`, and `tqdm`).

To create the environment, ensure you have **Anaconda** or **Miniconda** installed ([download here](https://www.anaconda.com/download)), then run:

```bash
conda env create -f environment/environment.yml
```

This creates a Conda environment named `astrophysics`.

### Activating and Deactivating the Environment

Activate the environment before running any scripts:

```bash
conda activate astrophysics
```

To deactivate the environment when finished:

```bash
conda deactivate
```

## Running the Pipeline

The `modules/` directory contains the main execution script **`run_clustering.py`**. Because the path resolution utilities in `module_data_path.py` look for project folders relative to `..`, navigate to the `modules/` directory before running the script:

```bash
cd modules
python run_clustering.py
```

### Configuring Execution Stages

At the top of `modules/run_clustering.py`, the `stages` list controls which stage of the pipeline is executed:

```python
stages = [1]  # Set to [1], [2], [3], [4], or [5]
```

Modify this list to run the desired stage (from `1` to `5`).

## Pipeline Stages

### Stage 1: Data Cube Smoothing, Edge Masking, and Moment 8 Maps
Preprocesses the raw spectral cubes ($^{12}\text{CO}$, $^{13}\text{CO}$, and $\text{C}^{18}\text{O}$) and generates peak intensity (Moment 8) maps before and after spatial smoothing.

- **Process**:
  1. Computes unsmoothed Moment 8 maps (`cube_mom8`) across the velocity range $[-50, 50]\text{ km s}^{-1}$.
  2. Generates a rotated rectangular edge mask (`mask_edges`) saved to `mask/mask_edges.npy`.
  3. Plots the unsmoothed Moment 8 maps with the edge mask overlay (`plot_mom8_not_smoothed`).
  4. Applies Gaussian spatial smoothing (`cube_smoothing`) channel-by-channel to each spectral cube.
  5. Computes and plots the smoothed Moment 8 maps (`cube_mom8`, `plot_mom8`).
- **Outputs**:
  - `fitsfiles/dr21_<emission>_mom8_not_smoothed.fits`
  - `fitsfiles/dr21_<emission>_smoothed.fits`
  - `fitsfiles/dr21_<emission>_mom8.fits`
  - `mask/mask_edges.npy`
  - `plots/dr21_<emission>_mom8_not_smoothed.pdf` & `plots/dr21_<emission>_mom8.pdf`

---

### Stage 2: Hierarchical Clustering with Astrodendro
Identifies molecular cloud structures (leaves/clumps) in the smoothed $^{12}\text{CO}$ data cube using hierarchical dendrograms (`astrodendro`).

- **Process**:
  1. Computes the 3D position-position-velocity (PPV) dendrogram (`make_clustering`) using configurable hyperparameters:
     - Noise level: $T_{\text{rms}} = 2.0\text{ K}$
     - Minimum threshold: $T_{\text{min}} = 3.0\,T_{\text{rms}}$
     - Minimum significance: $T_{\Delta} = 2.0\,T_{\text{rms}}$
     - Minimum volume: $n_{\text{vox}} = 500\text{ voxels}$
  2. Extracts a PPV physical catalog (`make_catalog`) of the identified leaf structures (computing centroids, major/minor axes, position angles, and exact areas).
  3. Extracts 2D sky projection masks (`make_mask`) corresponding to the velocity slice of maximum area for each leaf.
  4. Plots the Moment 8 map overlaid with the identified cluster contours and leaf indices (`make_plot_clusters`).
- **Outputs**:
  - `catalog/dr21_catalog_12co.csv`
  - `mask/dr21_12co_masks.npy`
  - `plots/dr21_12co_max_astrodendro_contours.pdf`

---

### Stage 3: Cluster Pruning & Catalog Refinement
Filters out spurious or noisy clusters identified by visual inspection and compares the cluster catalog before and after pruning.

- **Process**:
  1. Plots the Moment 8 map with fitted cluster ellipses prior to pruning (`plot_mom8_comparison` with `dropped=False`).
  2. Removes user-specified cluster indices (`drop_list = [3, 4, 5, 9, 10, 11]`) from both the CSV catalog and the 3D mask array (`catalog_mask_drop`).
  3. Plots the cleaned Moment 8 map with the remaining cluster ellipses (`plot_mom8_comparison` with `dropped=True`).
- **Outputs**:
  - `catalog/dr21_catalog_12co_dropped.csv`
  - `mask/dr21_12co_masks_dropped.npy`
  - `plots/dr21_12co_catalog_not_dropped.pdf` & `plots/dr21_12co_catalog_dropped.pdf`

---

### Stage 4: Gaia Star Classification & Bayesian Parallax Distance Estimation
Cross-matches Gaia astrometric/photometric data with the pruned molecular cloud mask and computes individual stellar distances.

- **Process**:
  1. Converts the raw Gaia VOTable catalog in `data/` into CSV format if not already converted (`vot_to_csv`).
  2. Projects stellar Galactic coordinates $(l, b)$ onto the WCS pixel grid of the $^{12}\text{CO}$ Moment 8 map and classifies stars as **on-cloud** (`on_cloud = True`) or **off-cloud** (`on_cloud = False`) using the collapsed 2D cloud footprint (`classify_and_filter_stars`).
  3. Applies quality and distance cutoffs following Yan et al. (2019): minimum parallax ($\varpi \ge 0.25\text{ mas}$) and minimum $G$-band extinction uncertainty ($\sigma_{A_G} \ge 0.05\text{ mag}$).
  4. Computes Bayesian stellar distance estimators (mode $r_{\text{mode}}$, median $r_{\text{median}}$, 5th and 95th percentiles, and normalization factor) using an exponentially decreasing space density prior (`distance_parallax` & `Distance.distance.main_exp`, based on Bailer-Jones 2015).
- **Outputs**:
  - `catalog/dr21_gaia_classified.csv`
  - `catalog/distances.csv`

---

### Stage 5: Extinction Baseline Subtraction & MCMC Cloud Distance Estimation
Determines the distance to the molecular cloud by modeling the jump in net stellar extinction ($A_G$) along the line of sight using Markov Chain Monte Carlo (MCMC) sampling.

- **Process**:
  1. Fits a monotonically increasing baseline to the off-cloud stars using weighted **Isotonic Regression** (`baseline_subtraction`) and subtracts it from all stars to obtain the net cloud extinction ($A_{G,\text{net}}$).
  2. Runs an ensemble MCMC sampler (`run_mcmc` via `emcee`) on the on-cloud stars to fit a 5-parameter Bayesian step model $\theta = (D, \mu_1, \sigma_1, \mu_2, \sigma_2)$, where:
     - $D$: Distance to the molecular cloud ($\text{pc}$)
     - $\mu_1, \sigma_1$: Mean and dispersion of foreground star net extinction
     - $\mu_2, \sigma_2$: Mean and dispersion of background star net extinction
  3. Generates the MCMC posterior corner plot (`corner`) and exports the median cloud distance and 16th/84th percentile uncertainties to JSON.
- **Outputs**:
  - `catalog/dr21_net_extinction.csv`
  - `catalog/dr21_final_distance.json`
  - `plots/dr21_baseline_fit.pdf`
  - `plots/dr21_mcmc_corner.pdf`

## Core Modules & Exploratory Notebooks

### Python Modules (`modules/`)
- **`run_clustering.py`**: Main pipeline controller executing `stage1()` through `stage5()`.
- **`module_clustering.py`**: Implements `make_clustering`, `make_catalog`, `make_mask`, `make_plot_clusters`, and `catalog_mask_drop` using `astrodendro`.
- **`module_utils.py`**: Implements spectral cube operations (`rms`, `smooth`, `cube_mom0`, `cube_mom8`, `cube_smoothing`, `mask_edges`), plotting utilities (`plot_mom8`, `plot_mom8_not_smoothed`, `plot_mom8_comparison`), Gaia data processing (`vot_to_csv`, `classify_and_filter_stars`, `distance_parallax`), and statistical inference (`baseline_subtraction`, `log_prior`, `log_likelihood`, `log_posterior`, `run_mcmc`).
- **`module_data_path.py`**: Provides `cube_data_path()`, `plot_data_path()`, `fits_data_path()`, `mask_data_path()`, and `catalog_data_path()` to locate repository directories automatically.
- **`Distance/` (`distance.py`, `pyrallaxes.py`)**: Implements Bayesian distance posterior probability density functions (uniform and exponentially decreasing priors, distance modulus, and transformed parallax methods) to infer stellar distances from Gaia parallaxes.

### Jupyter Notebooks (`notebooks/`)
- **`Astrondendro_exploratorio.ipynb`**: Interactive notebook for loading $^{12}\text{CO}$ spectral cubes, testing `astrodendro` hyperparameters, and inspecting 3D dendrogram structures via `d.viewer()`.
- **`VOT_file_read.ipynb`**: Exploratory notebook demonstrating how to parse Gaia `.vot` (VOTable) files using `astropy.io.votable` and convert them into `pandas` DataFrames.
